# Lucia TUI 优化计划

日期：2026-07-13
范围：`crates/agent-tui`（本体，不涉及插件渲染路径）
原则：最小正确改动、复用现有模式、每批独立可验收

## 背景与现状

TUI 已完成的部分：首屏字标（渐变 + 阴影）、圆角输入盒与运行状态标题、用户消息块
（背景色 + 连续竖条 + 预换行）、工具结果多行预览与 diff 着色、Markdown 主题统一、
状态栏分段（品牌 / 模型 / 目录 / git 分支 / ctx tokens）、运行耗时、Esc 三级行为、
翻阅位置角标、输入水平滚动、终端恢复守卫。

剩余优化集中在两条线：输入编辑体验、长会话阅读效率。

## 批次一：输入与阅读小改动

四项相互独立，可单独提交，均只动 `app_state.rs` / `chat.rs` / `conversation.rs`。

### 1.1 输入历史回溯（已按修正方案落地）

- 目标：`Ctrl+P` 召回上一条已提交输入、`Ctrl+N` 反向；进入回溯态后 `↑`/`↓` 可继续导航。
- 修正记录：最初设计"输入为空时 `↑` 召回"上线后劫持了消息滚动——空输入是翻阅
  历史的常态，且备用屏下鼠标滚轮被终端映射为方向键，等于禁用滚动。入口改为
  终端惯例的 `Ctrl+P`/`Ctrl+N`，`↑`/`↓` 保留给滚动与多行输入内的光标移动。
- 验收：召回后可编辑再发送；回溯中输入任意字符退出回溯态；历史不含空串与连续重复；
  空输入按 `↑` 滚动消息区而非进入回溯。

### 1.2 编辑快捷键补全

- 目标：补齐终端惯例编辑键。
- 改动点：`handle_key` 新增 `Delete`（向前删除）、`Ctrl+W`（删除光标前一个词）、
  `Alt+←` / `Alt+→`（按词移动光标）；词边界按空白与 ASCII 标点划分，兼容附件标签
  （删除跨过标签时走 `prune_attachments` 现有逻辑）。
- 验收：中英文混合输入下光标移动与删除按显示预期工作；附件标签被拆散时附件同步移除。

### 1.3 整页翻页与回底

- 目标：`PgUp` / `PgDn` 从固定 5 行改为按视口高度整页滚动；到达底部自动恢复跟随
  （现有逻辑保留）；新增 `Ctrl+End` 直接跳回底部。
- 改动点：`App` 记录 `last_viewport: u16`（`chat.rs` 渲染时写入，与 `last_max_scroll`
  同位置）；`scroll_up` / `scroll_down` 调用处传入视口高度减一。
- 验收：长会话翻页步进等于可视行数减一；任意位置一键回底。

### 1.4 代码块视觉区分

- 目标：助手回复中的 fenced code 块与正文明确分层，不引入 syntect。
- 改动点：`conversation.rs` 的 `split_markdown_segments` 仿照表格分支切出
  ``` 围栏块，新增 `MdSegment::Code`；渲染为左侧 `▎` 竖线 + muted 前景，
  首行右侧以暗色标注语言名；围栏行本身不渲染。
- 验收：多语言围栏块正确切分；未闭合围栏按代码块渲染到文末；表格与代码块相邻时互不干扰。

## 批次二：多行输入编辑器（大项，独立立项）

- 目标：支持 Shift+Enter（及 Ctrl+J）插入换行；输入盒随内容自动长高（1 到 6 行，
  超出后内部垂直滚动）；多行粘贴保留换行（移除现有"换行替换为空格"的降级逻辑）。
- 改动点：
  - 光标模型：`input: String` 保留，光标改为字节偏移 + 派生的行列计算，或改为
    `Vec<String>` 行模型（实现时二选一，倾向前者以减小 diff 面）。
  - `chat.rs`：输入区 `Constraint::Length(3)` 改为按内容行数动态计算；
    光标定位改为（行，列）双轴；水平滚动逻辑仅对超宽单行生效。
  - `handle_paste`：删除换行压平；`UserSubmission` 与会话持久化天然支持多行文本，无需改动。
  - 布局联动：`render_main` 的分区高度、命令预览高度上限需同步复核。
- 风险：光标移动（↑↓ 在多行输入内与消息滚动的语义冲突）需要明确路由规则——
  输入为多行时 ↑↓ 优先在输入内移动，到达首/末行后再交给消息滚动。
- 验收：粘贴多行代码原样保留；输入盒高度 1-6 行自适应；两种特性组合
  （`--features plugins` / `--no-default-features`）测试全过。

## 批次三：TUI 内会话管理（大项，批次二完成后评估）

- 目标：不退出进程即可新建会话、恢复最近会话、从列表选择会话。
- 改动点：极简选择层（全屏或浮层列表，复用 `session_store.list()` 与
  `load_startup_session` 现有能力）；键路由新增一个模态状态；切换时复用
  `handle_agent_done` 的会话重建路径。
- 前置：与 Command 插件的 `/resume` 类命令职责划分需先确认，避免重复实现。

## 打磨项（穿插处理）

- ctx 占比：配置新增可选 `model.context_window`；有值时状态栏 `◔ 5.3k` 升级为
  `◔ 43% · 86.9k`，占比超过 80% 转黄、95% 转红。
- 滚动高度估算误差：`wrapped_height` 按显示宽度整除估算，与 Paragraph 词边界换行
  存在 1-2 行偏差，影响"↓ N 行"角标精度；方案为自实现与渲染一致的换行计数，
  或评估 ratatui `line_count` 的可用性。

## 验证与提交约定

- 每项完成后运行：`cargo test -p lucia`、`cargo test -p lucia --no-default-features`、
  `cargo clippy -p lucia --all-targets`、`rustfmt --check`（仅本次触碰的文件）。
- 涉及视觉的改动以 `bun run install:tui` 重装后人工确认截图效果。
- 提交信息用简体中文 `<type>: <描述>` 格式；工作区存在其他 agent 的未提交改动时，
  由使用者统一提交。
