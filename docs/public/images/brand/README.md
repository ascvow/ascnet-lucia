# Lucia 应用图标

三个圆角模块在 2x2 网格中拼出字母 L，右上角留空形成负空间；右下模块使用主题强调色朱红，表示被点亮的模块。L 对应项目名，模块结构对应 Core 与多个插件组合成的 Agent 结构。

## 文件

- `lucia-icon.svg`：深色底板主版本，32 网格、1024 名义尺寸，矢量源文件。
- `lucia-icon-light.svg`：浅色底板备选版本。
- `lucia-icon-{16,32,64,128,256,512,1024}.png`：深色版本各尺寸导出。
- `lucia-icon-light-{16,32,64,128,256,512,1024}.png`：浅色版本各尺寸导出。

## 配色

| 用途 | 值 |
| --- | --- |
| 底板顶部 | `#2B2723` |
| 底板底部 | `#171513` |
| 模块 | `#E0DED8` |
| 强调模块 | `#E23D52` |

浅色版本底板为 `#F7F3EC` 到 `#E7DFD2`，模块为 `#2A2622`，强调色不变。配色沿用 `crates/agent-tui/src/theme.rs` 的暖灰底、正文色与用户强调色，底板明度做了轻微调整。

## 使用

- 16px 是最小尺寸；更小或单色场景请直接使用矢量文件重新导出，不要额外添加描边、文字或阴影。
- 不要改变模块数量、相对位置或强调色；强调色只用于右下模块。
- 深色底板版本适用于深浅背景；浅色底板版本用于浅色界面或印刷。
