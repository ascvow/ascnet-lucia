# 动态工作流插件

该插件参考 Claude Code 的动态任务列表，在 WASM Guest 内维护单一任务列表：任务可以在执行过程中随时追加、修改、取消或删除；依赖齐备的任务自动派生 Host 授权的 `worker` Agent 执行，无需封存或手动推进。任务协议、依赖调度和失败处理归插件所有；模型、服务商、工具权限与全局资源上限仍由 Host 控制。

插件激活时会注入独立的 developer 提示：仅在任务包含多个阶段或明确依赖关系时维护任务列表，简单的一次性任务不创建。

## 工具

- `task_create`：批量创建任务，依赖可引用已有任务或同批任务；就绪任务立即自动派生。
- `task_update`：把失败或已取消的任务重置为 `pending` 重跑、取消任务、修改待处理任务的提示词或依赖，或删除未运行且无人依赖的任务。
- `task_list`：同步运行结果后返回全部任务状态；待处理任务附带 `blocked_by` 阻塞依赖。
- `task_get`：读取单个任务的完整详情，包括执行输出与错误。

## 调度语义

- 无需封存或手动推进：每次任务工具调用与任务界面渲染都会同步运行中任务的终态，并在并行上限（4）内按创建顺序自动派生就绪任务。
- 失败不冻结列表：依赖失败任务的下游保持等待并在快照中标记 `blocked_by`，由主 Agent 决定重置重跑、修改依赖或取消。
- 依赖输出注入：任务启动时自动附带其直接依赖的最终输出。

任务状态只保存在当前插件组件实例内，卸载后不会恢复。需要跨进程恢复时，应由应用接入插件持久 KV 或版本化存储服务。

## 任务界面

存在待处理、运行中或失败任务时，输入框上方显示紧凑进度架，包含完成、运行、等待和失败数量；全部任务完成或取消后自动隐藏。按 `Enter` 或点击进入任务列表后，可用上下方向键选择任务，按 `r` 手动刷新一次同步与调度；已启动任务可按 `Enter` 进入对应 Agent 主界面，查看事件并发送 steering 或成功会话的后续输入。

## 构建与测试

```bash
cargo build --offline --manifest-path examples/plugins/workflow-plugin/Cargo.toml --release --target wasm32-wasip2
cargo test --offline --manifest-path examples/plugins/workflow-plugin/smoke-tests/Cargo.toml
```
